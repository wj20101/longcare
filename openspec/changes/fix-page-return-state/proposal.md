## Why

导航审查发现服务完成页重复重建首页且不同退出入口清理不一致；客户评估后返回详情可能显示旧数据，返回客户列表会重置分页和位置。修复这些局部问题，保留已确认的护理业务限制，不扩展导航架构。

## What Changes

- 服务完成页仅弹出自身，复用此前保留的首页；必要的选中项目清理归入服务成功结束处理，不依赖用户选择哪种返回入口。
- 客户详情重新成为当前前台页面时查询最新详情，不增加跨页面结果回传。
- 客户列表普通返回保留搜索条件、已加载分页和滚动位置；仅首次加载或条件变化重置列表。
- 明确保留倒计时页退出回首页、禁止回到服务前序步骤重新操作的业务例外；不修改其行为。

## Capabilities

### New Capabilities

- `sales-page-return-state`: 客户详情返回刷新和客户列表浏览状态保留。

### Modified Capabilities

- `service-completion-navigation`: 完成页返回复用原首页，服务成功后的必要清理不依赖返回入口。

## Impact

涉及 App 导航注册、服务完成 UI、NFC 服务结束清理、销售详情/列表及其 ViewModel 和回归测试。无新增依赖、网络接口、数据库迁移、H5 方法、结果关联机制或厂商 SDK 调整。保留现有未提交改动；不提交或推送，不提交线上业务数据。
