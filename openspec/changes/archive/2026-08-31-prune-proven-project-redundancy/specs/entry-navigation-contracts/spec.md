## ADDED Requirements

### Requirement: 开始服务直接进入 NFC 身份核验
护理人员从服务单触发开始服务时，应用 SHALL 使用完整订单上下文直接进入开始服务模式的 NFC 身份核验，不得插入没有业务决策作用的设备选择中间目的地。

#### Scenario: 护理人员开始服务
- **WHEN** 护理人员在可开始的服务单上触发开始服务
- **THEN** 应用导航到开始服务模式的 NFC 身份核验目的地
- **AND** 目的地收到发起操作时的完整订单上下文
- **AND** back stack 不包含设备选择中间目的地

#### Scenario: NFC 身份核验返回
- **WHEN** 护理人员从开始服务模式的 NFC 身份核验返回
- **THEN** 应用返回发起开始服务操作的有效业务页面
- **AND** 不显示已退役的设备选择界面
