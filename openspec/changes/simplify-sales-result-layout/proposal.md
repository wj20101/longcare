## Why

信息提交结果页的普通字号按钮仍为横排，与用户要求的上下排列不符；设备相关提示中的“评估设备”需要简化为“设备”。评估结果页已是竖排，本次统一两页按钮组间距并保留现有业务行为。

## What Changes

- 两个结果页按钮固定上下排列、同宽，继续/查看操作在上、返回/完成操作在最下方，保留现有样式和点击行为；不再按字体大小切换横排。
- 销售设备流程用户可见文案中的“评估设备”统一简化为“设备”，不改蓝牙广播中的真实设备名。
- 按用户补充记录正式环境尚未部署，正式联调暂缓；保留既有现场现象，不将设备授权提示推断为已查明的厂商绑定问题。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `evaluation-design-presentation`: 增加结果页按钮纵向排列与设备名称简化的展示要求。

## Impact

- 仅涉及 `:app` 销售页面、字符串资源、对应 UI 测试及相关文档。
- 不修改接口、导航、SDK 环境配置或 Token 流程，不新增通用框架、兼容分支或依赖。
- 外部依赖：正式环境部署后再完成原有真实检测和上传验收；离线 UI 验证不依赖正式环境，也不代替在线验收。
