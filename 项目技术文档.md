# 长护险项目技术文档

## 📋 项目概述

**项目名称**: 长护险 (Long Care)  
**包名**: `com.ytone.longcare`  
**当前版本**: v1.0 (Build 13)  
**编译日期**: 2025年11月29日  
**最低SDK版本**: 24 (Android 7.0)  
**目标SDK版本**: 34 (Android 14)  
**编译SDK版本**: 36  

### 项目简介

长护险是一款专为护理人员设计的Android移动应用，用于管理和记录长期护理保险服务。应用提供了完整的护理服务流程管理，包括用户身份认证、服务订单管理、位置追踪、人脸识别验证等核心功能。

## 🏗️ 技术架构

### 架构模式

项目采用 **Clean Architecture + MVVM** 架构模式，具有清晰的层次划分：

```
┌─────────────────────────────────────────┐
│         Presentation Layer              │
│   (UI Components - Jetpack Compose)     │
├─────────────────────────────────────────┤
│          ViewModel Layer                │
│    (State Management - StateFlow)       │
├─────────────────────────────────────────┤
│          Domain Layer                   │
│   (Business Logic - Use Cases)          │
├─────────────────────────────────────────┤
│           Data Layer                    │
│  (Repository Pattern - Room + Retrofit) │
├─────────────────────────────────────────┤
│         Data Sources                    │
│    (Remote API + Local Database)        │
└─────────────────────────────────────────┘
```

```kotlin
@Inject
lateinit var nfcManager: NfcManager

override fun onNewIntent(intent: Intent?) {
    super.onNewIntent(intent)
    intent?.let {
        if (it.action?.startsWith("android.nfc.action") == true) {
            nfcManager.handleNfcIntent(this, it)
        }
    }
}
```

```kotlin
/**
 * 安全的API调用包装
 * 统一处理异常、Token过期、网络错误
 */
suspend fun <T> safeApiCall(
    dispatcher: CoroutineDispatcher,
    eventBus: AppEventBus,
    apiCall: suspend () -> BaseResponse<T>
): ApiResult<T> {
    return withContext(dispatcher) {
        try {
            val response = apiCall()
            when (response.resultCode) {
                1000 -> ApiResult.Success(response.data)
                401 -> {
                    eventBus.emit(AppEvent.Unauthorized)
                    ApiResult.Error("未授权", 401)
                }
                else -> ApiResult.Error(response.resultMsg, response.resultCode)
            }
        } catch (e: Exception) {
            ApiResult.Error(e.message ?: "网络错误", -1)
        }
    }
}
```

### 协程使用规范

```kotlin
@HiltViewModel
class MyViewModel @Inject constructor(
    private val repository: MyRepository,
    @IoDispatcher private val ioDispatcher: CoroutineDispatcher
) : ViewModel() {
    
    // 使用viewModelScope
    fun loadData() {
        viewModelScope.launch {
            // UI操作在Main线程
            _uiState.value = UiState.Loading
            
            // IO操作在IO线程
            val result = withContext(ioDispatcher) {
                repository.getData()
            }
            
            // 回到Main线程更新UI
            _uiState.value = when (result) {
                is ApiResult.Success -> UiState.Success(result.data)
                is ApiResult.Error -> UiState.Error(result.message)
            }
        }
    }
}
```
