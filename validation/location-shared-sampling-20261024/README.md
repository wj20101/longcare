## 机制证据与剩余边界

此前两机独立 USB/JDWP 调用链捕获新网络输入被 SDK `LocFilter` 替换成旧 tick、observer 拒发；前台和后台都可发生。另一次五分钟真实拔线的公开白名单日志，两机各记录 9 次旧结果替换，原始回调均为 0，CPU 与订单检查仍推进。全局公开日志没有输入 tick 或 observer 判定，不能把九次替换直接等同九次完整链路，也不能用于确认原生请求归属。

正常停止生命周期清理历史状态是本次策略的依据；公开 stop 没有底层终止确认，静默间隔不等于 SDK 确认。该版本部分旧 HTTP 错误可广播给当前 observer，应用 listener 代次只能排除旧 public listener，无法完整识别 SDK 内部跨轮转发。子码 0403 表示泛化的请求/响应异常，零网络耗时可能来自统计实体缺失；都不足以确定具体网络根因。当前没有证据证明正常 stop 直接生成 0403。
