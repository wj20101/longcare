## Purpose

保证一次性 QLZ 检测凭证不被用于第二次 SDK 授权，覆盖授权重试、退出重进及页面重建，并让上传阶段的凭证失效能够保留本次结果恢复，不改变检测成功后的结果和报告流程。

客户端统一连接 QLZ 正式环境，与用户确认的 SDK key 和服务端正式凭证保持一致，不保留可误启用的测试环境开关。

## ADDED Requirements

### Requirement: 检测使用厂商正式环境

客户端 SHALL 使用固定 SDK 默认的 `https://openapi.qiaolz.com` 正式地址，保留用户确认可用于正式环境的现有 SDK key。Debug 与 Release MUST 使用一致的正式 SDK 环境，不自动回退测试环境；LongCare API 地址与 Token 接口契约不变。

#### Scenario: 应用初始化检测 SDK
- **WHEN** 应用在任一构建类型中初始化 QLZ SDK
- **THEN** 不启用测试或本地模式，授权及检测上传使用正式服务，检测上传路径为 `/sdk/assess/upload`

#### Scenario: 正式服务不可用
- **WHEN** 正式服务鉴权失败或请求失败
- **THEN** 按现有业务错误与本规格的凭证恢复规则处理，不切回测试环境或更换业务 API

#### Scenario: 发布配置核验
- **WHEN** 校验正式构建配置
- **THEN** 构建事实与风险提示不再声称已删除的测试模式仍开启，签名、质量门禁及未解决的厂商风险检查保持有效

### Requirement: 新的检测授权必须使用新获取的凭证

客户端 SHALL 在每次新的 SDK 授权前向 `/V1/Sale/GetCheckToken` 获取凭证，并只交付一次。已交付凭证 MUST NOT 被缓存为下一次授权的输入，也不得持久化用于页面重建后重放。

#### Scenario: 取消检测后重新搜索
- **WHEN** 用户从检测页返回设备页，原检测会话已取消，然后再次开始搜索
- **THEN** 系统获取新 Token 后建立新会话，不复用上一会话凭证

#### Scenario: 授权失败后重试
- **WHEN** 一次 SDK 授权失败且用户重试
- **THEN** 系统先重新获取 Token，再发起一次新授权，不重新提交已用凭证

#### Scenario: 宿主重建
- **WHEN** 页面恢复但原 UI 持有的 SDK 会话已销毁
- **THEN** 再次开始检测必须重新获取 Token，不重放 ViewModel 或保存状态中的旧凭证

#### Scenario: 存活会话继续扫描或重连
- **WHEN** 已授权会话未关闭，用户重新扫描或重连设备
- **THEN** 系统复用当前会话执行对应操作，不重复授权或无故重新获取 Token

### Requirement: 上传鉴权恢复保留本次检测结果

客户端 SHALL 区分上传鉴权失效与普通上传失败。对于厂商明确的鉴权失效，系统 SHALL 在当前检测流程内最多自动恢复一次：获取新 Token、重新授权、重传保留的同一份结果。系统 MUST NOT 因刷新凭证清空待上传数据、重新测量或生成另一条记录。

#### Scenario: 上传明确拒绝凭证
- **WHEN** SDK 上传回调返回厂商定义的凭证失效错误
- **THEN** 系统保留本次检测数据及 recordId，成功获取新 Token 并授权后重试原记录
- **AND** 只有上传成功后才能进入结果页查询 GetCheckResult

#### Scenario: 普通网络上传失败
- **WHEN** 上传失败未明确表示凭证失效
- **THEN** 保持原有手动重试同一份数据的行为，不自动重新检测或把所有错误当作 Token 失效

#### Scenario: 凭证恢复失败或连续拒绝
- **WHEN** 新 Token 获取失败、为空、重新授权失败，或自动恢复后再次发生凭证失效
- **THEN** 停止自动操作，显示可理解的失败提示和退出入口，不回退到旧 Token 或无限刷新
- **AND** 未关闭会话前不主动丢弃本次待上传数据；只有明确成功才能展示检测完成

### Requirement: 凭证请求与当前检测流程一致

客户端 SHALL 防止重复点击和旧请求完成触发多次 SDK 授权；凭证结果只允许交付给仍有效的当前客户检测流程。Token MUST NOT 写入日志、持久化或用户提示。

#### Scenario: 获取中重复点击
- **WHEN** 同一次启动或恢复的 Token 请求仍在进行，用户重复点击
- **THEN** 最多保留一个有效请求和一次 SDK 授权交付

#### Scenario: 离开页面或切换客户
- **WHEN** Token 请求未完成时用户退出检测或切换客户
- **THEN** 旧请求返回不得启动会话、覆盖新客户状态或触发旧结果上传

#### Scenario: 新凭证获取失败
- **WHEN** Token 接口失败或返回空凭证
- **THEN** 不调用 SDK 授权和上传，保留明确的失败提示，不继续使用已消费凭证
